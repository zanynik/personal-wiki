# Systems, Root Nodes, and Leverage Points

**Core idea:** A systems-thinking layer: root causes, logical solutions, leverage, self-correcting fields, and structural design.

## Working Definition

Many surface problems are treated as symptoms of deeper root nodes. The task is to find interventions that change the generating structure, not just the visible output.

## Main Threads

- Problems are repeatedly reframed as outputs of deeper systems rather than isolated failures.
- Root-node thinking asks which change would make many other changes easier.
- Logical solutions must include emotional, social, and incentive realities.
- Self-correcting systems are preferred over brittle systems that require constant policing.

## Guiding Questions

- What root nodes generate many visible problems?
- How can systems be designed to self-correct?
- Where should attention intervene for maximum humane leverage?
